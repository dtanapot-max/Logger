VANILLA LOGGER / NO DEPENDENCIES

Logger เล็ก ๆ
ใช้ร่วมกันได้ทุกหน้าเว็บ

JavaScript ธรรมดา + CSS ธรรมดา พร้อมแถบ log ด้านล่างจอ เปิดไฟล์นี้ได้ทันที ไม่ต้องติดตั้งแพ็กเกจ ไม่ต้อง build และไม่ต้องเชื่อมต่ออินเทอร์เน็ต

01 / ลองใช้งาน

กดปุ่มเพื่อเพิ่มรายการ แล้วกด [ขยาย] ที่แถบล่าง เลือกระดับเพื่อกรอง หรือลากขอบบนเพื่อปรับความสูง

เริ่มต้นพับเก็บ • เก็บล่าสุด 200 รายการ • ตัวเลขนับเฉพาะรายการที่ยังเก็บอยู่

02 / นำไปใช้กับหน้าอื่น

คัดลอก logger.js และ logger.css ไปไว้ด้วยกัน แล้วเพิ่มโค้ดนี้ในหน้า HTML ของคุณ Logger จะสร้างแถบให้เอง

<!-- ใน <head> -->
<link rel="stylesheet" href="logger.css">
<script src="logger.js" defer></script>

<!-- ก่อน </body> หรือในไฟล์ JS ของแอป -->
<script>
document.addEventListener('DOMContentLoaded', function () {
  Logger.init();
  Logger.info('APP', 'เริ่มทำงานแล้ว');
  Logger.success('SAVE', 'บันทึกสำเร็จ', { id: 42 });
});
</script>

ใช้ Logger.init() หลังมี document.body แล้ว เรียกซ้ำได้โดยไม่สร้างแถบซ้อน ส่วนรายการที่เขียนก่อน init จะรอแสดงเมื่อสร้างแถบ

Logger.info('APP', 'เปิดหน้ารายการ');
Logger.warn('API', 'ตอบกลับช้า', { ms: 1200 });
Logger.error('SAVE', 'บันทึกไม่สำเร็จ', new Error('Example'));
Logger.success('SAVE', 'บันทึกสำเร็จ', { id: 42 });
Logger.debug('FORM', 'ค่าระหว่างทำงาน', { dirty: true });

// รูปแบบกลาง: category, level, message, meta
Logger.log('API', 'info', 'โหลดข้อมูลแล้ว', { count: 12 });

category ตั้งเองได้ ไม่ผูกกับระบบใด ข้อความและข้อมูลจะแสดงเป็นข้อความ ไม่ตีความเป็น HTML รองรับ Error, BigInt และ object ที่อ้างวนกัน

03 / ตั้งค่าและเรียกใช้

Logger.init({
  max: 200,          // เก็บ 1–2000 รายการ ล่าสุดอยู่ท้าย
  open: false,       // เริ่มพับเก็บ
  height: 240,       // ความสูงรายการ ปรับให้พอดีกับจอ
  persist: false,    // true = จำ log และหน้าตาด้วย localStorage
  key: 'myapp.logs', // แยกข้อมูลแต่ละแอปเมื่อเปิด persist
  snapshot: () => ({ page: 'orders', pending: 2 })
});

ตั้งค่าครั้งแรกเท่านั้น หากต้องการเปลี่ยนให้เรียก Logger.destroy() แล้ว init ใหม่ เมื่อเปิด persist จะใช้ตัวกรอง สถานะพับ และความสูงที่บันทึกไว้ก่อนค่าตั้งต้น ค่า snapshot ต้องเป็นฟังก์ชัน synchronous และจะถูกเรียกเมื่อ export หรือคัดลอก

คำสั่งหน้าที่
Logger.filter('error')แสดงระดับที่เลือก ใช้ 'all' เพื่อแสดงทั้งหมด
Logger.toggle(true)เปิดแถบ; false เพื่อพับ; ไม่ส่งค่าเพื่อสลับ
Logger.clear()ล้าง log ทั้งหมดรวมรายการที่บันทึกไว้
Logger.data()คืนสำเนารายการ ไม่แก้ไขข้อมูลภายในโดยตรง
Logger.export()คืน JSON string ของทุกระดับ พร้อมเวลา ตัวกรอง และ snapshot
await Logger.copy()คัดลอก JSON ใน Markdown; คืน true เมื่อสำเร็จ หากไม่ได้จะแสดงช่องให้คัดลอกเองและคืน false
Logger.setMode('online')สีจุดสถานะ: online ฟ้า, offline เขียว, standby เหลือง; แอปเป็นผู้กำหนดเอง
Logger.destroy()ถอดแถบ คืนพื้นที่ ล้างหน่วยความจำ และยกเลิก event listeners; ข้อมูลที่เปิด persist ยังคงอยู่

ปุ่ม ⧉ AI คัดลอกทุกระดับที่ยังเก็บอยู่ ไม่จำกัดตัวกรองที่เลือก ไม่มีการส่งข้อมูลออกเครือข่ายอัตโนมัติ ตัวอย่างนี้ไม่เก็บ log ข้ามการโหลดหน้า หากเปิด persist ให้เลือกเก็บเฉพาะข้อมูลที่เหมาะกับ localStorage

04 / ใช้กับเลย์เอาต์ต่าง ๆ

แถบใช้ position: fixed และติดกับขอบล่าง viewport จอแคบเลื่อนชุดตัวกรองซ้าย–ขวาได้ โดยปุ่มหลักยังอยู่ในจอ หน้าที่เลื่อนทั้งเอกสารจะมีพื้นที่สำรองท้ายหน้าให้อัตโนมัติ

ถ้าแอปเลื่อนเฉพาะ div หรือมี footer แบบ fixed ให้ใช้ตัวแปรความสูงที่ Logger อัปเดตให้ เลือกใช้เฉพาะส่วนที่ตรงกับเลย์เอาต์ของแอป:

/* สำหรับแอปที่เลื่อนเนื้อหาภายใน div */
.app-scroll {
  padding-bottom: calc(16px + var(--log-space, 0px));
}

/* สำหรับ footer ที่ fixed อยู่ด้านล่างอยู่แล้ว */
.app-footer {
  bottom: var(--log-space, 0px);
}

/* ปรับค่าได้ใน CSS ของแอป */
.log-dock {
  --log-width: 1120px;
  --log-z: 10000;
}

แนบแถบกับ body โดยตรง ควรหลีกเลี่ยง transform/filter บน html หรือ body ซึ่งเปลี่ยนจุดอ้างอิงของ fixed CSS ของ logger ใช้ prefix log-; ส่วนตัวอย่างใช้ log-demo เท่านั้น ถ้ามี CSS global ที่ใช้ !important ให้ตรวจการทับสไตล์ของหน้านั้น

ใช้ Tab ไปที่ขอบจับ แล้วกด ↑/↓ เพื่อปรับความสูง, Home/End เพื่อปรับต่ำสุด/สูงสุด, Enter หรือ Space เพื่อย่อ/ขยาย และ Escape เพื่อพับเมื่อโฟกัสอยู่ใน logger

ย้ายจาก StructuredLogger เดิม

เอา script, HTML แถบ logger เดิม และการ init เดิมออกก่อน ใช้ 2 ไฟล์ใหม่นี้แทน เปลี่ยน StructuredLogger.info(...) เป็น Logger.info(...) โดยลำดับ category, message, meta เหมือนเดิม เปลี่ยน stateProvider เป็น snapshot ไม่มีการดัก console หรือ global error ให้อัตโนมัติ ให้แอปเรียก Logger ในจุดที่ต้องการ

มีเพียง 3 ไฟล์: logger.js · logger.css · index.html — เปิดด้วย browser รุ่นปัจจุบัน
